為中古韻書和《康熙字典》的反切構擬出現代粵音
============================================

## 目錄説明

### 中古音系

本目錄擺放紀錄中古音工具書的反切及聲韻資料，並為這些反切擬出相對應的現代粵語讀音。

四本中古音工具書分別是：

- 《大宋重修廣韻》，簡稱「廣韻」
- 《集韻》
- 《增修互注禮部韻略》，簡稱「增韻」
- 《附釋文互注禮部韻略》，簡稱「韻略」

由於條目眾多，故以「聲」和「攝」為單位分檔存放。

為方便比較，聲韻仍採《廣韻》系統，故《集韻》聲母不會有非敷奉微四母。

### 康熙字典

本目錄放置從《康熙字典》提取的反切資料。假設這些反切反映中古音系統，推測它們的音韻地位，並據此擬出相應的粵語讀音。
